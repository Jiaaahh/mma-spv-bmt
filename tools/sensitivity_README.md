# 多轴敏感性复算入口（本轮为核验修补，不是新增实验）

## 在统一送审附件中的位置与命令

将 `recompute_sensitivity.py` 放至附件 `tools/`，将 `sensitivity_sources/` 原样放至同一 `tools/` 目录。原有证据目录为 `evidence/`，不改其中任何文件或 manifest。

从附件根目录运行：

```text
python tools/recompute_sensitivity.py --bundle-root evidence --output-dir checks/sensitivity
```

依赖仅为 Python 标准库与 NumPy；本轮实际环境为 Python 3.12.14、NumPy 2.3.5、Windows 11。脚本在导入 NumPy 前将常见计算后端线程环境变量限制为 2。输出仅写入指定的新目录，禁止输出至冻结证据目录内部。三个输入 CSV 先核对固定 SHA-256，再检查配对键、正确标志、类别范围及完整笛卡尔网格。

本轮实测三项共约 8.0 秒 CPU 时间跨度；这是本机一次运行的壁钟耗时，不是通用速度承诺。只读取三个原始预测表，未训练模型、未重跑推理、未使用 GPU，也未执行全套 666,000 行主统计审查。

## 结果与边界

| 项目 | 既有稿件记录 | 本轮复算 | 核验边界 |
|---|---|---|---|
| 基础识别准确率差，多轴95%区间/百分点 | [9.83, 21.00] | [9.8888889, 21.0000000] | 独立 multinomial 路径；未恢复历史随机数调用路径，不能称逐位重放 |
| 扩展验证准确率差，多轴95%区间/百分点 | [9.94, 20.19] | [9.9444444, 20.1944444] | 已复用历史 crossed 函数，按字符字符串排序、每批1,000次、各轴依次整数抽样 |
| 多预算ΔnAUBC，多轴95%区间 | [0.0274, 0.1693] | [0.0274074074, 0.1693287037] | 独立 multinomial 路径；仅与已报告四位小数一致，不称历史随机数路径逐位重放 |

以上均为事后敏感性分析。主分析的字符簇条件区间另行核验，不被这里的区间取代。基础识别只有2种字体，扩展验证和多预算各只有4种字体，三者都只有5个映射种子，不据此推断任意字体、其他生成器或患者总体。有限 Monte Carlo 的微小端点差异不单独证明原稿错误；本轮不替换历史区间。

每项均使用100,000次配对乘积经验自助法。基础识别与预算沿用最新独立审查的50批×2,000次 multinomial 重采样；预算先在每个字符×字体×映射单元内以非等距梯形权重 [8,16,24,32,16]/96 积分，再重采样。扩展验证沿用历史100批×1,000次整数抽样，复核的是主对比的三轴区间，不包含原历史文件的全部消融比较或单轴敏感性条目。

## 历史来源保留

`sensitivity_sources/` 中 E1 脚本、统计模块、历史敏感性 JSON 与审查脚本均按字节原样保存，SHA-256 见 `source_manifest.json`。这些原脚本用于追溯，不作为附件的可移植执行入口；部分含历史绝对路径。可移植入口仅为 `tools/recompute_sensitivity.py`，只使用同目录的来源文件和用户传入的 `--bundle-root`。

`historical_and_review_excerpt.json` 保存历史稿件的多轴区间原文、源文件 SHA-256 以及最新独立审查结果摘要和其 SHA-256。基础识别原始多轴调用路径在限定范围查找中未找到，未通过枚举种子或调整抽样算法拟合历史端点。

## 供补充S10使用的精简文字

多轴敏感性分析的独立入口为 `tools/recompute_sensitivity.py`，运行 `python tools/recompute_sensitivity.py --bundle-root evidence --output-dir checks/sensitivity`，依赖 NumPy。扩展验证主对比沿用存档历史函数的字符字符串顺序和每批1,000次整数抽样，重得[9.944444,20.194444]个百分点；基础识别与多预算采用标明的独立配对乘积重采样路径。基础识别独立结果[9.888889,21.000000]与历史记录[9.83,21.00]的下端略有差异，历史随机数调用路径尚未逐位重放；多预算独立结果[0.0274074,0.1693287]与稿件四位小数一致。该入口不替换历史区间，也不宣称全部历史统计逐位复现。来源、哈希与核验边界见 `tools/sensitivity_sources/`，输出见 `checks/sensitivity/sensitivity_recomputed.json`。
